这篇是实践文，素材来自本机已 Distill 的笔记《蒂亚戈·福特与第二大脑方法》（整理于 2026-11-04），以及笔记里列出的 Forte Labs 公开页。不编造素材外的经历或数据。专有名词保留英文，并给中文对照。

## 一句话

第二大脑（Building a Second Brain）要解决的不是「存更多笔记」，而是：**把读到、想到、碰到的信息，变成可检索、可复用、能推进项目的外脑。**

核心流程是 **CODE**：捕捉（Capture）→ 整理（Organize）→ 提炼（Distill）→ 表达（Express）。整理一章用的架子是 **PARA**。

## CODE：把消费变成产出

| 步骤 | 英文 | 含义 | 落地 |
|------|------|------|------|
| 捕捉 | Capture | 只留共鸣的 | 链接、摘录、想法先扔收件箱；不问完美分类 |
| 整理 | Organize | 按可行动性 | PARA：项目 / 领域 / 资源 / 归档 |
| 提炼 | Distill | 抽精华 | 加粗、高亮、渐进摘要；一眼能用 |
| 表达 | Express | 交出来 | 草稿、清单、帖子、方案——笔记为人服务 |

中间产物叫 **中间包（Intermediate Packets）**：可复用的半成品（会议要点、调研列表、大纲片段），方便拼装成最终作品。

## PARA：按「能不能行动」分四格

PARA 是书中「整理」一章的骨架，也有独立薄册《PARA 方法》（2023）。

- **项目（Projects）**：有目标、有期限的短期努力
- **领域（Areas）**：长期责任（健康、财务、品牌…），有标准无终点
- **资源（Resources）**：以后可能有用的主题资料
- **归档（Archives）**：前三类里已停 / 搁置的

读法建议（来自笔记）：想快上手 → 先读《PARA 方法》；想懂为什么 → 再读《打造第二大脑》（2022）。先建 PARA 文件夹，再慢慢跑满 CODE。

## 最小可行：今天就能开跑

不要先读完再动手。按 CODE 跑一轮即可。

1. **今天**：固定一个库。只建 PARA + 收件箱，别加标签体系。
2. **捕捉（每天 5–10 分钟）**：凡共鸣的 → 收件箱。标准只有一条：以后可能用得上，或让你有感觉。
3. **整理（每周 1 次）**：对收件箱问「这推进我哪个项目？」→ 项目；否则领域 / 资源；死掉的 → 归档。
4. **提炼（写之前）**：打开相关笔记，只留能直接进稿的句子；其余折叠或删。
5. **表达（绑项目）**：每个项目至少有一个「下一次要交的东西」；写作 / 方案时先搜外脑，再空白开写。

## 作者与书（来源内事实）

蒂亚戈·福特（Tiago Forte）：Forte Labs 创始人，个人知识管理实践者与教练。把「外置数字记忆」做成可教体系；课程与书名即《打造第二大脑》。笔记还记了他做过湾区产品咨询、和平队、拉美小额信贷，以及文章曾见于《哈佛商业评论》《大西洋月刊》《纽约时报》等——这些据作者自述 / 出版页，本文不当作独立核验结论。

主要作品角色（按笔记表格）：

| 作品 | 角色 |
|------|------|
| 《打造第二大脑》（2022） | 全流程 CODE + 外脑理念 |
| 《PARA 方法》（2023） | 整理实操薄册；可先读这个上手 |
| Praxis 散文集等 | 扩展阅读（见官网书单） |
